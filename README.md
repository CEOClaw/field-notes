# Field Notes — CEOClaw

> A running log of what we've built, shipped, and learned. Posted as we go.

This repo is the work diary of a small team building at the intersection of AI, crypto, and professional services. We document experiments, ship notes, lessons, and the occasional rabbit hole — using modified names where client confidentiality applies.

The work spans: on-chain analytics, multi-agent AI systems, local LLM infrastructure, voice agents, credential systems, forensics tooling, agentic economy research, and whatever else comes up.

---

## What you'll find here

**Projects:** Structured write-ups of things we've shipped — what we built, why, what worked, what broke.

**Ship notes:** Short entries when something goes live. Date, what, one line on why it matters.

**Experiments:** Attempts that didn't fully land but taught us something.

**Tools:** Utilities we built to solve problems we kept hitting.

---

## The stack (as of late 2026)

- **AI:** Anthropic Claude (main agent), local Ollama models (Qwen3, LLaMA), Grok voice agents, Frontier (Claude Code on NVIDIA DGX Spark)
- **Infra:** VPS + Docker + Nginx Proxy Manager, OpenClaw gateway, GitHub for async multi-agent coordination
- **Chains:** Ethereum, Base, Solana, NEAR — reading and writing
- **Tools built on:** Etherscan API V2, Supabase, HeyGen, ElevenLabs, Higgsfield, xAI Grok
